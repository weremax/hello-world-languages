## Setup

Each folder contains a different programming language with a hello/ folder that contains the necessary files of each and a README.md.

Simple hello world code in various programming languages. Ada, C, C++, Cobol, Crystal, Elixir, Fortran, Gleam, Go, Haskell, Idris, Lisp, Lua, Nim, Rust, Scala, Tcl, Zig and more.

No specific system was used I have used some of the following:
- Mx Linux
- CachyOS
- MacOS
- Windows 11 Pro
- and many more based on which system I happened to have been using that day.
